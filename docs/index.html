💻 ความต้องการของระบบ & วิธีตรวจไฟล์
  • Windows 10/11 (64-bit) — ไม่ต้องติดตั้ง Python หรือโปรแกรมเพิ่มเติม
  • อินเทอร์เน็ตสำหรับดาวน์โหลดวีดีโอ
  • ตรวจ checksum หลังดาวน์โหลด (PowerShell): Get-FileHash .\VideoDownloaderGUI.exe -Algorithm SHA256 แล้วเทียบกับค่าด้านบน
  • ถ้า SmartScreen แสดงคำเตือน: กด More info → Run anyway

🚀 วิธีใช้งานสั้น ๆ

  1. เปิดโปรแกรม วางลิงก์วีดีโอ (ใส่ได้หลายลิงก์ บรรทัดละลิงก์)
  2. เลือกคุณภาพและโฟลเดอร์ปลายทาง
  3. กด ▶ เริ่มดาวน์โหลด — เสร็จแล้วกด 📂 เปิดโฟลเดอร์ได้เลย
⚖️ ใช้เฉพาะกับคอนเทนต์สาธารณะที่คุณมีสิทธิ์ดาวน์โหลดตามกฎหมายและเงื่อนไขของแต่ละเว็บไซต์ ห้ามใช้ละเมิดลิขสิทธิ์หรือเผยแพร่คอนเทนต์ส่วนบุคคลที่เจ้าของไม่ได้ยินยอม
