เวอร์ชันถัดไป Unreleased

✨ Added — ฟีเจอร์ใหม่

  • Android: เอนจิน yt-dlp + ffmpeg จริงในแอป — พร้อมใช้งานกับลิงก์ทั่วไป: รับลิงก์จากเว็บใดก็ได้ (หลายพันเว็บ) • HLS/DASH + merge video+audio ด้วย ffmpeg + แปลง mp3 • โหมดสำรองแยกสื่อจากหน้าเว็บ (lazy-load / JSON / manifest / iframe — ใช้กับ player.html ฝัง player ได้) • เลือกคุณภาพ best/1080/720/480/mp3 • อัปเดตเอนจิน yt-dlp อัตโนมัติครั้งแรกหลังติดตั้ง • บันทึกเข้า Downloads ผ่าน MediaStore • APK ~156 MB (แพ็ก Python+ffmpeg: arm64-v8a/armeabi-v7a/x86_64) • เทสต์ scraper 10 เคส + build debug/release ผ่าน
  • เบราว์เซอร์ในแอป (WebView2) — พิมพ์ URL เปิดหน้าเว็บที่ต้องการในแอป (pywebview รันเป็นโปรเซสลูก สื่อสารผ่าน localhost; ช่อง URL ตามการคลิกลิงก์อัตโนมัติ; ถ้าเปิดไม่ได้ fallback ไปเบราว์เซอร์ระบบ)
  • ปุ่ม "ดาวน์โหลดวีดีโอที่กำลังแสดง" — สแกนหน้าที่เปิดอยู่: video/source ที่กำลังเล่น + performance entries (manifest .m3u8 ที่ hls.js โหลด, ไฟล์ตรง) + iframe player → จัดลำดับดาวน์โหลดอัตโนมัติ (ไฟล์ตรง → HLS/DASH ผ่าน yt-dlp → iframe)
  • ระบบ log อย่างละเอียดเพื่อวิเคราะห์/ดีบัก — logs/vdl.log หมุนเวียน 1 MB × 5: หัวเซสชัน (เวอร์ชัน/OS/ffmpeg/yt-dlp), ข้อความภายใน yt-dlp, ทุกขั้นของโหมดสำรอง/เบราว์เซอร์ + traceback ครบ • เมนู ช่วยเหลือ → เปิดโฟลเดอร์ log… • เบราว์เซอร์แยกไฟล์ vdl-browser.log
  • โหมดสำรองจับสื่อได้กว้างขึ้น — รองรับเว็บได้มากกว่าเดิม: iframe player ภายนอก (ตามเข้าไปหน้า player ลึก 1 ระดับ สูงสุด 5 iframe) • สตรีม HLS/DASH (.m3u8/.mpd ส่งต่อให้เอนจิน yt-dlp) • lazy-load data-src/data-video-src • สื่อใน JSON/สคริปต์ (player config / JSON-LD, รวมแบบ escape) • ลิงก์ endpoint ไม่มีนามสกุล (ตรวจจาก Content-Type)
  • ส่ง Referer ของหน้าต้นทางตอนโหลดสื่อ และตอนส่ง manifest/iframe ให้เอนจิน yt-dlp (ผ่าน CDN ตรวจ hotlink) • อ่านหน้าเว็บตาม charset จริง (รองรับ windows-874) • วางข้อความปน URL ได้ (แตกลิงก์อัตโนมัติ) • ข้าม blob:/data: URL
  • ชุดทดสอบ 16 → 61 เคส — fixture จำลองเว็บจริง (iframe + lazy-load + HLS + JSON), เทสต์ localhost server ออฟไลน์, เทสต์ระบบ log + การจัดลำดับ candidate

เวอร์ชัน 1.1.0 v1.1.0 — 28 กันยายน 2026

✨ Added — ฟีเจอร์ใหม่

  • แอป Android (Kotlin + NewPipeExtractor) — APK ติดตั้งได้ รับลิงก์แชร์ เลือกคุณภาพ ดาวน์โหลดลง Downloads พร้อม notification
  • โหมดสำรอง (fallback download) — เมื่อ yt-dlp ดึงไม่สำเร็จ แอปสลับไปแยกลิงก์สื่อจากหน้า HTML อัตโนมัติ: รองรับไฟล์ .html ในเครื่อง, ลิงก์ไฟล์สื่อตรง (mp4/mp3/ฯลฯ) และการดึงหน้าเว็บหา <video>/<source>/<a>/og:video — พร้อม progress และปุ่มยกเลิก
  • โมดูล html_media.py + หน้าทดสอบ tests/test.html (วิดีโอตัวอย่างสาธารณะ CC) + ชุดทดสอบ tests/run_tests.py — 16 เคส ผ่านทั้งหมด
  • สถานะใหม่ในตาราง: "ลองโหมดสำรอง…" และ "สำเร็จ (สำรอง) ✓"

เวอร์ชัน 1.0.0 v1.0.0 — 28 กันยายน 2026

🎉 รีลีสแรกอย่างเป็นทางการ

✨ Added — ฟีเจอร์ใหม่

  • แอป GUI (tkinter) ดาวน์โหลดวีดีโอจากเว็บไซต์สาธารณะด้วยเอนจิน yt-dlp
  • รองรับหลายลิงก์พร้อมกัน (คิวดาวน์โหลด) พร้อมตารางแสดงสถานะรายการ
  • เลือกคุณภาพ: ดีที่สุด (mp4) / 1080p / 720p / 480p / แยกเสียงเป็น MP3
  • แถบความคืบหน้า + เปอร์เซ็นต์ + ความเร็ว + เวลาที่เหลือ แบบเรียลไทม์
  • ปุ่มยกเลิกทั้งหมด — หยุดงานกลางคันอย่างปลอดภัย (ผ่าน progress hook)
  • จำกัดความเร็วดาวน์โหลด: 1 / 5 / 10 MB/s หรือไม่จำกัด
  • Bundle ffmpeg ผ่าน imageio-ffmpeg — รวมไฟล์วีดีโอ+เสียงและแปลง MP3 ได้ทันที
  • แพ็กเป็น EXE ไฟล์เดียวด้วย PyInstaller (onefile, windowed) พร้อมไอคอนและ version resource
  • คู่มือ AGENT.md สำหรับผู้ร่วมพัฒนา/AI agent
  • เอกสาร README / RESEARCH / CHANGELOG ทั้ง Markdown และ HTML
  • หน้าเว็บดาวน์โหลดบน GitHub Pages — ดึง release ล่าสุดจาก GitHub API อัตโนมัติ พร้อมปุ่มดาวน์โหลดและ SHA256 checksum
  • GitHub Actions: build EXE และสร้าง release อัตโนมัติเมื่อ push tag v* + deploy Pages

  • ffmpeg-win-x86_64 v7.1 (~25 MB) bundle ใน EXE
